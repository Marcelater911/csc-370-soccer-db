# csc-370-soccer-db
Contributors: Abhishek, Marcelo, Kevin and Jawin.

## Idea
This project is built to capture the soccer league management system of Europe's top 5 soccer leagues which are namely ***LaLiga***, ***Premier League***, ***Ligue 1***, ***Serie A***, and ***Budesliga***. The Idea is to simulate the backend architecture of a digital soccer media tracking platform which allows users to quickly find information of latest soccer games, upcoming fixtures, updated league standings, match statistics, and to know more about core entities (player, coaches, teams, leagues) of the game to follow it better as a soccer fan.
