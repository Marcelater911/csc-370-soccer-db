# AI Usage

This document explains the use of Generative AI on this project.



At present our team has used Generative AI for Ideation and design purposes such as drafting/brainstorming requirments, identifying key relations, BCNF Violations; and for formatting SQL DDL Code to match the standard SQL formatting.<br><br>

We also used Generative AI to review our SQL for syntax and logic errors, explain concepts (composite keys, derived attributes, views and window functions), suggest fixes for some code (example queries 1, 4 and 5, and v_player_ages), and help with planning and documentation.

AI Models used:

Anthropic: Sonnet 5<br>
OpenAI: ChatGPT
